Xpanse is a personal expense tracker application built to help user manage their income and expense
in one place.

FEACTURES
­- Dashboard: View total income, expense, and balance.
- Add Transaction: Add new income and expense records.
- Edit Transactions: Update existing transations.
- Delete Transactions: Remove transactions when needed.
- Search Transactions: Find transactions by name.
- Clear Search: Reset the search instantly.
- Form Validation: Prevent empty or invalid transaction entries.
- Local Storage: Save transaction data in the browser so it remains available after refreshing the page.

TECHNOLOGIES USED
- React.js
- JavaScript
- HTML
- CSS Vite
- Browser Local Stroge
